# Pi 5 검증 결과

검증 대상은 Raspberry Pi OS Trixie의 `network-manager 1.52.1-1+rpt4`와 백포트 `1.52.1-1+rpt4+codex1`입니다.

## 변경 효과

기존 버전은 정상 연결 이력이 있는 WPA-PSK 프로필에서도 인증 실패 시 즉시 새 비밀번호를 요청했습니다. 백포트는 연결 이력과 `connection.auth-retries` 설정을 반영해 저장된 비밀번호로 재시도합니다.

정상 연결을 먼저 완료한 시험 프로필에 임시로 잘못된 비밀번호를 설정하고, `auth-retries=0`에서 각각 45초간 비교했습니다.

| 동작 | 원본 | 백포트 |
|---|---:|---:|
| 저장된 비밀번호 재사용 | 0회 | 8회 |
| 새 비밀번호 요청 | 1회 | 0회 |

유한 재시도, 새 프로필의 비밀번호 요청, 연결 취소, 정상 비밀번호 복구 후 재연결, 프로필 재로드 후 `auth-retries=0` 유지도 확인했습니다.
