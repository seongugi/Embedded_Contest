## 반복시험 방법

센서 IPC에 사고 알림을 100ms 간격으로 입력하고, Wi-Fi Direct 전송부터 수신 후 IPC 전달까지 기록했습니다. 실제 송수신 코드의 ACK 대기와 재전송을 그대로 사용했습니다. 사건 식별자로 중복 패킷을 합쳐 고유 수신 건수를 계산했습니다.

수신한 **39,990건 모두 IPC로 한 번씩 전달**했습니다. 중복 IPC 전달·큐 초과·디코딩·변환 오류·시험 중 프로세스 재시작은 모두 **0건**입니다.
